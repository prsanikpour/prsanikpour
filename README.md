## ⚙️ Engineering Workflow & Standards
I treat my side projects like production systems. Here is how I work:

*   **Clean Architecture:** Strict separation of concerns (e.g., `config/`, `db/`, `handler/`, `middleware/`, `service/`).
*   **Database Safety:** Using `sqlc` to generate type-safe Go code directly from raw SQL files (no ORMs).
*   **Quality Assurance:** Integration testing with `Testcontainers` (using real databases, not mocks) and static analysis via `golangci-lint`.
*   **Git Discipline:** Frequent, focused commits using conventional messages, ensuring a clear and maintainable history.
