## ⚙️ Engineering Workflow & Standards
I treat all codebases like production systems. Here is how I consistently deliver reliable software:

*   **Clean Architecture:** Strict separation of concerns (e.g., `config/`, `db/`, `handler/`, `middleware/`, `service/`) to ensure scalability and ease of maintenance.
*   **Database Safety:** Utilizing `sqlc` to generate type-safe Go code directly from raw SQL files, bypassing heavy ORMs for maximum performance and predictability.
*   **Quality Assurance:** Implementing robust integration testing with `Testcontainers` (using real databases, not mocks) and ensuring code quality via `golangci-lint`.
*   **Git Discipline:** Maintaining frequent, focused commits using conventional commit messages to guarantee a clear, readable, and revertible version history.
